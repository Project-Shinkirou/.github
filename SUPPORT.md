# Support / 求助与支持

## English

Looking for help with **ShinkiEMU** or another **Project-Shinkirou** project?

1. **Check the docs & FAQ first:** [Official Portal](https://project-shinkirou.github.io/) · [Quick Start](https://project-shinkirou.github.io/en/shinkiemu/docs/quick-start/) · [Troubleshooting](https://project-shinkirou.github.io/en/shinkiemu/docs/troubleshooting/) · [FAQ](https://project-shinkirou.github.io/en/shinkiemu/faq/)
2. **Questions & community tips:** Ask in [ShinkiEMU GitHub Discussions](https://github.com/Project-Shinkirou/ShinkiEMU/discussions).
3. **Report a bug or compatibility result:** Use the structured forms under [ShinkiEMU Issues](https://github.com/Project-Shinkirou/ShinkiEMU/issues/new/choose).
4. **Security vulnerabilities:** Report privately via [GitHub Security Advisories](https://github.com/Project-Shinkirou/ShinkiEMU/security/advisories/new).

## 简体中文

使用 **ShinkiEMU** 或 **Project-Shinkirou** 项目时遇到问题？

1. **先查文档与常见问题**：[官方门户](https://project-shinkirou.github.io/zh-cn/) · [快速上手](https://project-shinkirou.github.io/zh-cn/shinkiemu/docs/quick-start/) · [故障排查](https://project-shinkirou.github.io/zh-cn/shinkiemu/docs/troubleshooting/) · [FAQ](https://project-shinkirou.github.io/zh-cn/shinkiemu/faq/)
2. **提问与游玩交流**：前往 [ShinkiEMU GitHub Discussions](https://github.com/Project-Shinkirou/ShinkiEMU/discussions)。
3. **报告 Bug 或提交兼容性结论**：在 [ShinkiEMU Issues](https://github.com/Project-Shinkirou/ShinkiEMU/issues/new/choose) 选择对应表单。
4. **安全漏洞**：通过 [GitHub Security Advisories](https://github.com/Project-Shinkirou/ShinkiEMU/security/advisories/new) 私密报告。
